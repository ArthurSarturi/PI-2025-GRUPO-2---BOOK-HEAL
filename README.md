# PI-2025-GRUPO-2---BOOK-HEAL

Este é um projeto desenvolvido em **Python** com **Flask** e **MySQL** utilizando **Flask-SQLAlchemy** como ORM.

Antes de rodar o projeto, é necessário instalar as bibliotecas utilizadas.

---

## 🚀 Instalação
pip install Flask
pip install MySQLAlchemy
pip install controllers
pip install db
pip install flask_sqlalchemy

---

## 📖 Sobre o Projeto

Este projeto foi desenvolvido como parte da disciplina de Projeto Integrador do curso técnico integrado ao ensino médio Informática para Internet do Instituto Federal Catarinense Campus Concórdia.  
Ele tem como objetivo acolher os jovens através da leitura, criamos então o Book Heal um espaço que promove acolhimento, escuta e conversas 
significativas sobre saúde emocional, autoestima, identidade e outros temas da juventude. O fórum convida os participantes a indicar leituras, tirar dúvidas
e expressar sentimentos, construindo uma comunidade baseada no poder transformador das palavras.

As principais tecnologias utilizadas foram:  
- **HTML e CSS** → Para a estrutura e o design do site.  
- **Python (Flask)** → Para a lógica do servidor e integração com o banco de dados.  
- **MySQL** → Para armazenamento e gerenciamento das resenhas.

O projeto é dividido em camadas:  
- **Frontend** (HTML/CSS) Para a interface com o usuário.  
- **Backend** (Flask e Controllers) para as regras de negócio.  
- **Banco de Dados** (SQL) Para o salvamento das resenhas dos usuários.
